# Анализ продаж с помощью Pandas

## Описание проекта

Учебный проект по анализу данных с использованием библиотеки Pandas

Цель проекта - изучить работу с табличными данными, выполнить базовый анализ продаж и применить основные операции Pandas, аналогичные SQL-запросам: фильтрация, группировка, агрегация, сортировка и создание сводных таблиц

## Датасет

В проекте используется датасет **Superstore Sales Dataset** с Kaggle.

Датасет содержит информацию о заказах магазина: 
- дата заказа
- дата доставки
- способ доставки
- категория и подкатегория товара
- регион, страна, город, штат
- клиент
- сегмент
- название товара
- почтовый индекс
- продажи

## Используемые технологии

- Python 
- Pandas

## Основные результаты анализа

- **Категории:** Technology лидирует по продажам (827,5 тыс.), но отрыв от Office Supplies (705,4 тыс.) — наименьшей категории — составляет всего около 17%. Выручка распределена между тремя категориями относительно равномерно, бизнес не зависит критично от одной товарной группы.
- **Подкатегории (2018):** внутри категорий продажи распределены крайне неравномерно — Phones (104,7 тыс.) более чем в 120 раз опережает Fasteners (0,9 тыс.). Три подкатегории (Phones, Chairs, Binders) формируют заметно больше выручки, чем нижние 8-9 позиций вместе взятые. Ровная картина на уровне категорий скрывает сильную концентрацию продаж в узком наборе товаров.
- **Регионы:** West лидирует и по выручке (710,2 тыс.), и по числу заказов (3140), но за счёт объёма — средний чек тут ниже (226), чем в East и South. South при наименьшем числе заказов среди регионов (кроме Central) показывает самый высокий средний чек (243,5) — покупки реже, но крупнее. Central отстаёт по всем трём метрикам сразу.
- **Доставка:** среднее время чётко соответствует уровню сервиса — от Same Day (0,04 дня) до Standard Class (5 дней), разница между First Class и Standard Class — почти в 2,3 раза.
