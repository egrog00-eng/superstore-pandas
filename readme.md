# Анализ продаж с помощью Pandas

## Описание проекта

Учебный проект по анализу данных с использованием библиотеки Pandas

Цель проекта - изучить работу с табличными данными, выполнить базовый анализ продаж и применить основные операции Pandas, аналогичные SQL-запросам: фильтрация, группировка, агрегация, сортировка и создание сводных таблиц

## Датасет

В проекте используется датасет **Superstore Sales Dataset** с Kaggle.

Датасет содержит информацию о заказах интернет-магазина:
- дата заказа
- дата доставки
- категория и подкатегория товара
- регион
- способ доставки
- клиент
- сумма продаж

## Используемые технологии

- Python 
- Pandas

## Выполненные задачи

### Подготовка и проверка данных

- Загрузка данных из CSV-файла
- Проверка размера датасета
- Анализ структуры данных.
- Поиск пропущенных значений
- Проверка наличия дубликатов
- Преобразование дат из строкового формата в datetime

### Анализ продаж

- Определение временного диапазона данных
- Поиск 10 самых крупных заказов по сумме продаж
- Расчет общей суммы продаж по категориям товаров
- Анализ продаж по регионам
- Анализ продаж за отдельный год
- Определение самых прибыльных подкатегорий товаров

### Работа с датами

- Извлечение года из даты заказа
- Расчет времени доставки в днях
- Анализ среднего времени доставки в зависимости от способа доставки

### Анализ клиентов

- Определение топ-10 клиентов по общей сумме покупок

### Агрегация данных

- Использование `groupby()` для группировки данных
- Использование агрегатных функций (`sum`, `mean`, `count`)
- Создание сводной таблицы продаж по категориям и регионам с помощью `pivot_table()`

## Навыки, продемонстрированные в проекте

- Работа с DataFrame в Pandas
- Очистка и подготовка данных
- Фильтрация и сортировка данных
- Группировка и агрегация данных
- Работа с датами
- Анализ табличных данных
- Экспорт результатов в CSV
